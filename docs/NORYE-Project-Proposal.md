## 1. What You Are Building

A **mobile-responsive e-commerce storefront** for N Ō R Y E — an olfactory design line selling inspired 30ML Eau de Parfum for men and women.

The website allows customers to browse the product catalog, search perfumes, add items to a cart, and **complete orders via WhatsApp**. There is no online payment gateway; orders are handed off to the business through a pre-filled WhatsApp message.

This proposal documents work that has been **delivered and handed off** to the client.

---

## 2. Pages and Features Included

### Pages

| Page | Description |
|------|-------------|
| **Homepage** (`index.html`) | Hero section, featured perfumes, best sellers, shop-by-category, trust/features, about, footer |
| **Men's Collection** (`men.html`) | Full product grid for men's perfumes |
| **Women's Collection** (`women.html`) | Full product grid for women's perfumes |
| **Product Detail** (`product.html`) | Dynamic product page with description, notes, related items, and add-to-cart |

### Features Delivered

| Feature | Details |
|---------|---------|
| **Homepage hero** | Branded intro preloader, 3D rotating product showcase, gold brand styling |
| **Product catalog** | Product cards with images, prices, and “Inspired by” labels (~11 products) |
| **Collection views** | Grid and list toggle on men's and women's pages |
| **Product detail** | Image, description, perfume notes, related products |
| **Search** | Inline navbar search and search popup across the full catalog |
| **Shopping cart** | Add/remove items, quantity controls, cart badge, offcanvas “Your Bag” panel |
| **WhatsApp checkout** | Customer details form → pre-filled WhatsApp order message to business number |
| **UX & animations** | Scroll reveals, price animations, cart fly effect, paired CTA button effects, mobile navigation |
| **Deployment** | Static site ready for Vercel; source code on GitHub |

### Technology

- HTML5, CSS3, JavaScript (static site — no server required)
- Bootstrap 5, Swiper, AOS
- Cart stored in browser `localStorage`
- Hosting: Vercel (free tier) with optional custom domain
- Repository: [github.com/harry934/Norye-perfumes](https://github.com/harry934/Norye-perfumes)
